# Yuko — Cadência (Material You 3 Expressive)

Landing page interativa inspirada no **Material You 3 Expressive**, com 4 sementes de cor dinâmica (Claro/Escuro), formas orgânicas com morfismo tátil, física de mola (*spring*), *Split Button* e estúdio sonoro via Web Audio API.

## Arquivos
- `index.html` — Estrutura semântica HTML5
- `styles.css` — Tokens e temas Material You 3 Expressive
- `app.js` — Motor dinâmico de temas e síntese sonora
- `DESIGN.md` — Documentação de tokens, tipografia e formas
